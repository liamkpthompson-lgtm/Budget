# Liam & Amy Budget Portal 📊

A real-time joint household budget tracker, personal cashflow manager, and dynamic expense logging dashboard designed for seamless financial command. Built with HTML, Tailwind CSS, and Vanilla JavaScript, and hosted live via GitHub Pages.

---

## ✨ Key Features

- **Dual Dashboard Views:** Seamlessly switch between the **Joint Household Dashboard** and your **Personal Budget & Cashflow Tracker**.
- **Multi-Frequency Calculations:** Enter budget amounts in Monthly, Fortnightly, or Weekly views—all other frequency columns calculate and update automatically.
- **Dynamic Income Splits:** Automatically computes proportional income contributions and dynamic splits based on baseline earnings inputs (Liam & Amy).
- **Interactive Management:** 
  - **Add Categories:** Easily add new budget categories with custom names, groups/accounts, and target amounts.
  - **Edit Categories:** Modify category names, groups, or budget amounts on the fly.
  - **Delete Categories:** Remove unwanted rows with a single click.
- **Expense Logging & Syncing:** Log day-to-day transactions with custom dates, categories, descriptions, and amounts. Expenses instantly update your actual spend and remaining surplus.
- **Month Selector:** Filter budgets and logs month-by-month to track historical or upcoming spending.
- **Data Persistence:** Automatically saves all your edits, category adjustments, baseline inputs, and expense logs directly to your browser's `localStorage` so nothing is lost on refresh.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS (via CDN)
- **Logic:** Vanilla JavaScript (ES6)
- **Storage:** Browser `localStorage`
